# PaimenOS 0.70.1

## Weitere Korrekturen

- **„Zurück zum Menü“-Knopf** in der Firefox-Leiste: Die Breite richtet sich nach
  dem Text, englisches „Back to menu“ lief vorher über den Rand.
- **Speech Dispatcher** (`libspeechd2`, `speech-dispatcher`,
  `speech-dispatcher-espeak-ng`) gehört jetzt zur Installation und zu den
  Update-Paketen. Firefox zeigt damit nicht mehr „Speech Dispatcher library is
  missing“, wenn eine Webseite die Browser-Sprachausgabe nutzt (einfache
  espeak-Stimme).

## Sprachausgabe auf vorhandenen Geräten

Mit 0.70.0 fehlten Piper und die Stimmen auf Geräten, die per Update statt per
Neuinstallation aktualisiert wurden, weil Updates nur Debian-Pakete holen.

- `python3-venv` ist jetzt Teil der Update-Pakete.
- Der Boot-Dienst `paimenos-packages.service` installiert Piper und die Stimmen
  im Hintergrund nach (Unit `paimenos-speech-install`, rund 320 MB, Internet
  nötig), sobald die Sprachausgabe eingeschaltet ist und Piper fehlt. Boot und
  Webbereich warten nicht darauf.

Ablauf: Update einspielen, Sprachausgabe unter **Einstellungen** einschalten,
einmal neu starten. Sofort und von Hand:

```bash
sudo apt install python3-venv
sudo python3 /usr/local/lib/paimenos/current/tools/install-paimenos-speech.py
```

Der Fix greift erst, wenn 0.70.1 installiert ist; die Aktualisierung von 0.70.0
auf 0.70.1 holt nur `python3-venv`, Piper kommt danach beim nächsten Neustart.
